# 各专业图纸表达矩阵与打印控制（V2.1 提案）

> 配置：`data/sheet-expression-matrix.v2.1.json`。
> 当前仅定义重点与可见性逻辑，**没有在 AutoCAD 内自动执行**。

## 核心区别

- **图纸类型 SheetType**：这张图纸要解决什么施工问题。
- **视图模板 BaseView**：平面、地面、吊顶、机电、立面等基础显示环境；同一 BaseView 能服务多张图纸。
- **语义标签 SemanticTag**：墙、柜、砖缝、开关等对象语义，不等于 CAD 图层名，也不意味着每个标签新建一个图层。
- **图形表达 Role**：剖切粗线、轮廓、虚线、填充、遮罩等。
- **出图属性**：纸张/比例线宽预设 + 稳定命名 STB 的彩色/灰阶/黑白模式。

## 显示动作

| 动作 | 意义 | 典型例子 |
|---|---|---|
| FOCUS（重点） | 必须读得清楚，使用主要表达层级 | 电气图插座、地面图砖缝 |
| CONTEXT（背景） | 仍可见但低对比度，起定位参照作用 | 电气图中的家具、墙线 |
| HIDE（隐藏） | 当前图纸不显示但不删除数据 | 地面图中无关控制线 |
| CONDITIONAL（按条件） | 取决于项目特征、空间及对象状态 | 湿区防水、吊顶检修口 |

**重要**：FOCUS、CONTEXT、HIDE 只是视图/图纸目标。AutoCAD 实现可用视口图层覆盖、表示代理和独立注释图层组合；不能假设不分角色、混在同一图层中的实体可以单独变灰或隐藏。

## 典型图纸对比

| 图纸 | FOCUS 突出 | CONTEXT 弱化 | 建议输出 |
|---|---|---|---|
| 拆除墙体 | 拆除范围、拆改尺寸 | 需保留的现状墙 | COLOR（同时必须线型与说明） |
| 家具平面 | 家具、柜体、门窗、洁具 | 原有建筑底图 | GRAY |
| 地面铺装 | 地砖、分缝、起铺点、尺寸 | 建筑外轮廓及必要定位 | GRAY |
| 吊顶布置 | 吊顶边、灯具位置与标高 | 墙体及部分家具 | GRAY |
| 强电插座 | 插座、设备、定位尺寸 | 家具、柜体、墙 | COLOR |
| 开关控制 | 开关、灯位、控制关系 | 家具与建筑 | COLOR |
| 冷热水 | 管线、节点、洁具、尺寸 | 家具与建筑 | COLOR |
| 室内立面 | 墙面、柜门、构造、标高 | 材料填色 | GRAY |
| 节点详图 | 材料剖切、构造尺寸 | 次要背景 | BW |

## 显示与打印的独立设置

1. 屏幕颜色沿用已有 CAD 专业配色，切换图纸不修改全局图层颜色。
2. 单张图纸选基准视图 + 类型覆盖，决定重点、背景与隐藏。
3. 每个视口按纸张和比例确定纸面线宽；同一图纸中不同视口可以分别用1:50和1:10。
4. STB 仅映射出纸颜色，不覆盖对象线宽；四种 V2.1 STB 目前仍是目标配置，尚未制作/验证。
5. 图层有图层级显示控制，遮罩是带归属与足迹的实体级显示。不能通过一份全局“谁在谁上面”的表覆盖所有对象。
6. 若用户覆盖图层/样式/线宽，必须明确覆盖来源；无法解析的对象宁可报警，也不能静默消失。

## 输出前的五道审计关口

- 图纸清单：是否漏了需要的专业，是否有不适用的图纸。
- 图层与语义：未知对象、无法解析的表达标签。
- 绘制顺序：遮罩覆盖是否正确、是否与墙体等必要结构冲突。
- 打印：当前 STB 是否真实存在且被验证，Normal、TrueColor 是否导致漏彩。
- 人工验收：尺寸完整、图例明确、专业计算与现场条件已经人工审核。

## 推荐的数据流

`ProjectScope -> SheetSetTemplate -> SheetType -> SheetInstance -> BaseView + TypeExpression -> RepresentationRole + Layer -> Viewport Lineweight -> STB Color Mode -> PDF`

每一步都可以审计、覆写、追踪。**暂不连接插件，直到决策与 AutoCAD 实机验证通过。**

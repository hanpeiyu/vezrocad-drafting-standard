# 图形表达角色（Representation Roles）

这是 v2 相比 v1 的核心变化：**把物体是谁和它怎样画分开**。

数据源：[`../data/representation-roles.json`](../data/representation-roles.json)。表达角色是稳定的机器 ID，不直接要求每个角色有独立全局图层。

| ID | 功能 | 默认线宽 mm | 主要使用 |
|---|---|---:|---|
| `CUT_HEAVY` | 剖切粗线 | 0.50 | 墙/柱剖切 |
| `OUTLINE_PRIMARY` | 主轮廓 | 0.35 | 门/窗/家具/柜体外轮廓 |
| `OUTLINE_SECONDARY` | 次轮廓 | 0.25 | 内部分界 |
| `DETAIL_THIN` | 细节线 | 0.15 | 门缝、五金、开启线 |
| `HIDDEN_DASHED` | 隐线 | 0.15 | 隐藏结构、吊顶上方；**仅在图纸明确要求时输出，常规遮挡默认省略** |
| `CENTERLINE` | 中心线 | 0.13 | 定位与轴线 |
| `HATCH_PATTERN` | 材料纹理 | 0.13 | 砖缝、剖面图案 |
| `FILL_SURFACE` | 色块 | 0.13 | 收纳/区域示意 |
| `WIPEOUT_MASK` | 遮挡背景 | 不适用 | WIPEOUT，必须按绘制顺序处理 |
| `DIMENSION` | 尺寸标注 | 0.15 | 尺寸线 |
| `ANNOTATION` | 文字索引 | 0.18 | 索引、指示 |
| `UNDERLAY_FAINT` | 浅参照 | 0.13 | 需要打印的底图 |
| `NONPLOT_GUIDE` | 非打印辅助 | 0.13 | Plot=Off |

**WIPEOUT 的图层线宽是占位默认值，不代表遮罩依靠线宽产生遮挡。**

## 图层映射策略

1. **简单图块**：没有相互独立的轮廓和遮罩需求，则 Layer 0 + ByBlock，避免导入成百上千图层。
2. **复合块**：轮廓、细节和遮罩应有独立表现，可选共用 `通用-图块-*` 或特定构件子层（优先明确构件图层）。
3. **智能对象**：按 `semanticId + representationRole + viewId` 查规则映射目标图层；无规则时返回明确警告而不是默默落在 0 层。
4. 角色/图层/图纸套都可独立升级，避免一次性对已有 DWG 批量重绘。

## 相同对象的不同表达

- 智能墙平面：剖切粗线+填充；立面：可见轮廓/墙面造型线；节点：剖切与材料图例。
- 门平面：框线、扇线、开启弧、遮罩；立面：门框/门扇/门缝/五金。
- 智能柜：柜体、门缝、拉手、抽屉、隔板虚线、遮罩；收纳分析用色块是另一角色。
- 铺贴：边界、缝、填充以及起铺点，起铺点在施工图上是否标注由视图决定。

## 与表达语义的关系

插件侧的表达语义（Cut / Visible / Hidden 等）经 [`../data/semantic-to-role.json`](../data/semantic-to-role.json) 映射到本表角色，详见 [`13-与插件架构建议书的衔接.md`](13-与插件架构建议书的衔接.md)。

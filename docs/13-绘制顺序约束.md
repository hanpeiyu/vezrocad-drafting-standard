# V2.1 绘制顺序约束：从全局排序改为局部依赖图
> 状态：提案。机器数据：data/draw-order-constraints.v2.1.json。还没有 AutoCAD 执行器。

## 为什么不能给所有142层排一个顺序
AutoCAD 图层表的顺序不等于实体绘制顺序；图块、动态块、嵌套块、外参中的实体也可能拥有各自的前后关系。
因此使用 **局部有向无环图（DAG）+ 视图附加边 + 同一对象的遮罩约束**，而不是一个固定的图层数字排名。旧 representation-roles.json 的 drawOrderPriority 仅是历史提示，V2.1 不将其视为执行顺序。

## 基础规则
| 下面 | 上面 | 用途 |
|---|---|---|
| 参照底图 | 填色/纹理 | 防止背景干扰 |
| 地砖缝、材料纹样 | 有效范围内的家具/洁具遮罩 | 使表面铺贴不穿透构件 |
| 遮罩 | 所属构件轮廓、五金、柜门缝 | 构件自己不被遮住 |
| 家具遮罩 | 必须保留的墙体剖切轮廓 | 不吞噬墙体结构 |
| 构件轮廓 | 尺寸/标注 | 施工信息必须可读 |

例如马桶遮罩只能作用于洁具占地范围，不能简单把所有 WIPEOUT 提到所有地砖线以上；墙体需要保留的线不能被错误的遮罩覆盖。对于有交叠的对象，应计算相对遮挡及几何裁剪，不能仅靠单张顺序表。

## 执行器建议
1. 读取规则，根据当前 viewId 合并全局关系和视图关系；对每个节点进行环检测，若有环则报错且禁止写 DWG。
2. 对每个构件生成视图代理，先确定其背景/遮罩/填充/可见线，再将依赖关系落实到实际实体 DRAWORDER；普通块和动态块内部独立处理。
3. 对复杂交叉构件（门洞、墙柱连接、柜体靠墙）优先使用真正几何边界；不得用 WIPEOUT 伪造门洞。
4. 动态拉伸、镜像、可见性状态变化后重新验收遮罩足迹及顺序；必要时有局部重排与失败诊断，不应全图扫描。
5. 外参、嵌套块与对象跨块排序存在技术边界；在未通过 AutoCAD 2027 PDF 回归前不承诺全场景自动排序。

## 关键验收示例
- 平面家具图：柜体遮住地砖缝，柜门分缝可见，墙体轮廓不消失。
- 吊顶图：灯具遮罩盖过背景填充，但灯具外圈和符号不断线。
- 电气图：点位符号高于家具淡化背景，正确区分遮罩与透明色块。
- 节点详图：剖切边高于材料填充，同时标注和尺寸完整。

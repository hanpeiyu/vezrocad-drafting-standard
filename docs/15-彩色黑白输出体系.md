# V2.1 打印颜色：屏幕配色、STB 和线宽三者解耦
> 机器配置：data/print-color-profiles.v2.1.json。**当前只定义目标，不提供 V2.1 STB 二进制文件**。

## 推荐的组合，不是A3×比例×色彩的STB排列组合
屏幕编辑颜色采用一套固定专业配色（保留 V2 现有 ACI/TrueColor，不为打印切换重新给模型着色）。线宽采用按视口、比例决定的 Paper Lineweight Profile；打印颜色由四个互换的、样式名集合一致的命名 STB 定义。

| 模式 | 典型用途 | 颜色处理 |
|---|---|---|
| BW | 传统纯黑施工图 | 所有可打印图形黑色，遮罩例外 |
| GRAY | A3施工交底，主次清晰 | 主体黑、弱化对象按灰阶输出 |
| COLOR | 电气/给排/拆改技术交底 | 专业低饱和配色，不等于屏幕原色 |
| PRESENTATION | 客户沟通 | 温和低饱和颜色和浅色填充，注重可读性 |

## Stable Named Plot Styles
旧六个样式 VZ-MAIN、VZ-SOFT、VZ-FAINT、VZ-FILL、VZ-ACCENT、VZ-MASK 继续保留；V2.1 提案新增 VZ-ARCH、VZ-NEW、VZ-DEMO、VZ-ELECTRICAL、VZ-COLD-WATER、VZ-HOT-WATER、VZ-HVAC、VZ-UNDERLAY。
四套 STB **必须具有完全相同的样式名称**，只切换颜色，不覆盖线宽和线型；按需要使用视口 VP Plot Style 映射。

## 严格区分旧资源与新提案
- 当前仓库里的 assets/stb/VZ-A3-BW.stb 与 VZ-A3-COLOR.stb 属于 **V2旧六样式资产**，不能使用 V2.1新增的八个样式名。
- JSON 中的 VZ-BW-v2.1.stb 等只是**尚未生成、尚未验收的目标文件名**；不得让插件直接引用。
- AutoCAD 的 Normal 命名样式不会按自定义颜色映射，应扫描并警告。TrueColor、显式对象样式、嵌套块、Xref需单独验证。
- WIPEOUT 必须按遮挡几何与打印驱动处理，不能依靠“白线”或“黑色覆盖”来实现遮罩。
- 如果选择保持屏幕原色作为 COLOR 出纸，就会弱化真正的颜色解耦。要实现低饱和独立打印颜色，需对图层/对象赋稳定的语义命名样式，而不是仅使用 VZ-MAIN 一种样式。

## 验收门槛
1. 使用 AutoCAD 2027 生成/校验四份同名样式 STB，且每个样式 Lineweight / Linetype 均是 Use Object。
2. 对同一 A3/A2 DWG，在 BW / GRAY / COLOR / PRESENTATION 导出的 PDF 中量测线宽，确保只改颜色、不改线宽。
3. 测试浅灰细线、TrueColor、Normal、动态块、WIPEOUT、Xref，并补充纸样与打印机/驱动版本。
4. 未经验证，不得在程序内默默将新样式赋到旧 DWG，或把旧 STB 标为已符合 V2.1。

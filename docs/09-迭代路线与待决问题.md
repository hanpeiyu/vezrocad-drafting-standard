# 迭代路线与决策清单

本仓库是**长期演进的规范单一信息源**，与 VezroCAD 插件的 G0/G1 开发节奏解耦。

## 建议顺序

- **S0 当前：提案讨论**：冻结命名、基础角色、遮罩政策、STB 原则；不批量改旧文件。
- **S1 打印验证**：A3 样张、黑白/彩色和动态块遮罩，至少 15 项清单通过。
- **S2 对齐真实模板**：AutoCAD 导出原 DWT 图层表，制作一对一 / 一对多映射，保留人工审核。
- **S3 接入 SmartCAD**：先实现稳定数据契约、配置读取、按需建层、语义/角色映射、只读审计。
- **S4 智能视口/自动施工图**：切换视图模板、覆盖逻辑、内部绘制顺序回归测试。
- **S5 规范发布**：DWT（AutoCAD 实机生成）、CAD 安装包、不同图幅配置、版本迁移工具。

## 开放问题（Issue 逐项讨论）

1. 复合图块是否默认使用共用的 `通用-图块-*` 子层，还是按专业建立最小一组子层？
2. 遮罩统一使用 WIPEOUT，还是对特定对象使用背景填充？CAD 2027 / PDF 驱动兼容性是否一致？
3. A3 线宽 0.13 是否作为填充/弱线默认值？打印机是否丢线？
4. BW 需要“灰阶施工图”和“绝对纯黑图”两种输出选项吗？
5. 拆改图中怎样用线型/注释保证黑白可区分拆除与新建？
6. 立面是否采用单独编辑空间/块编辑器式工作模式，表示层如何分离？
7. 是否将同一套视图规则适配 AutoCAD 属性过滤图层和 SmartCAD 独立视图引擎？
8. 需要确认原 DWT 的真实图层表，建立迁移成本评估。

## 版本策略

- MAJOR：改变配置模式或语义契约。
- MINOR：新增图层、角色、视图模板，不破坏旧键。
- PATCH：更正文档、阈值或非破坏性配置。
- **未经实机验证的二进制 STB 必须保留实验性标签**，不能以版本号推断已经生产验收。

## GitHub 协作建议

- 默认**私有仓库**（含商业工作流和未来可能的项目数据）；仅放规范和匿名样张。
- 通过 Issue 讨论边界，通过 ADR 冻结决策；插件代码另一个仓库通过版本依赖引用 JSON。
- PR 必须跑结构校验，并附有需要的 A3 样张截图或测试记录。

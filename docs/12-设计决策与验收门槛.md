## 必须严格区分的三种“线”

- **业务实体**：墙、门、柜、插座，是构件/族语义，不能用线宽定义身份。
- **表达角色**：主轮廓、细节、隐藏、剖切等，是每张视图下的可替换画法。
- **CAD 属性**：图层、Lineweight、Linetype、Color、PlotStyle、Draw Order，是实际输出参数。

示例：一个衣柜实体同时输出轮廓线、门扇分缝、开门活动线和遮罩；是否需要独立CAD图层，取决于图纸套是否需要分别冻结、筛选和打印，而不是只看对象分类。

## 通过条件

1. D-001 至 D-004 需要各有 ADR 或明确的否决记录，才谈“架构冻结”。
2. `scripts/validate.py` 与 `scripts/verify_binary_assets.py` 均通过，仅算**结构合格**。
3. `docs/08-验收清单.md` 的 CAD 2027 实机 A3 PDF 样张通过，才算**打印合格**。
4. 所有图块遮罩必须验证对象遮挡、出图、块编辑与修改后的绘制顺序。
5. 与 `VezroCAD` 插件的接入必须以版本化 JSON 配置、语义键和兼容策略为前提。

## 迭代方式

开 Issue → 比较方案及代价 → 记录选择为 ADR → 更新样例与数据 → CI 检查 → CAD 样张复核 → 仅在验收通过后发布可用版本。

本仓库目前处于 **S0 规范讨论阶段**，不是稳定的施工图模板发行版。

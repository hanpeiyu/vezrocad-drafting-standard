# ADR-0002：纸面线宽与打印颜色分离、绘制顺序采用约束图
- 状态：**Proposed / 未接受**
- 日期：2026-11-12
- 背景：V2 虽有角色优先级和两套STB，但缺少跨比例线宽、跨对象遮罩相对顺序、独立彩色打印语义。

## 提议方案
- 规范采用局部相对绘制顺序 DAG（含视图附加边和对象级防遮挡规则），不硬编码142图层总排序。
- 比例相关线宽通过视口 VP Lineweight 和明确预设应用；STB始终保留对象线宽。
- 一套屏幕配色，打印颜色由同名样式集合的四套 STB 解决；不按纸张或比例复制 STB。
- LOD 仅影响显示代理，绝不改变原始构件真实几何。

## 反对方案及代价
1. 所有图层设置全局 draw order：嵌套块和对象重叠无法可靠表达，维护成本高。
2. 每种比例创建一份 STB：造成纸张×视图×模式组合爆炸，并诱发线宽逻辑重叠。
3. 仅使用 ByLayer 颜色直接彩色出图：屏幕亮色与低饱和技术出纸耦合，难独立控制。

## 接受条件
完整数据验证、实际 A3 PDF/纸样，以及动态块/遮罩/多视口灰彩同线宽验收；另外确认新STB风格集合，不可误标旧资源。
相关 Issue #1、#2、#4。

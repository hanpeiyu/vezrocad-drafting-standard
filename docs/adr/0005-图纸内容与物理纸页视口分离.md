# ADR-0005：图纸内容、物理纸张页与视口独立管理

- 日期：2026-11-12
- 状态：**Proposed / 待审议**
- 关联：`docs/23-图框图签纸空间规范.md`、`docs/24-图纸布局视口规范.md`、`docs/25-身份与表达编译契约.md`

## 问题

旧设计中“37种图纸类型”隐含每一项对应一张物理页，但设计师会在一张A3放家具平面+节点，或在一张纸里排两面立面。图框与图签占据纸面面积，不能仅靠“纸张净区宽高”判定实际出图。

## 决策提案

- `DrawingType`是图纸内容类别，`DrawingInstance`是某张逻辑图纸内容；
- `SheetPage`是物理Layout纸张，其`sheetUid`独立于图号和`drawingUid`；
- `ViewportInstance`负责将一个DrawingInstance放到SheetPage的布局槽位；
- 图签、图框、标题带、图号、修订和视口布局在纸空间1:1，模型保持真实几何尺寸；
- 选择A3或A2、比例和版面先生成多种可行方案并排序，设计师可以固定策略或手动确认；
- 图纸跨页索引以稳定UID解析，图号只作为对用户的显示编号；
- 图框/视口规则通过版本化管理器编辑，并通过不可变Git快照发给CAD插件。

## 不推荐方案

1. 一种图纸类型必须独占一张纸：无法表达一纸多视口、重复节点或双立面。
2. 图纸布局与模型共用图层全部直接打印：缺图框/视口边界独立控制。
3. 任意缩小比例以适配纸张：会牺牲施工信息可读性，且造成不同图纸间比例混乱。
4. 直接把DWG Handle或图号当作跨页永久主键：复制、重排、换页后索引可能断裂。

## 接受条件

独立MVP可验证 A3 单图、A3 主图+节点、A2 大户型方案；编号变化不破坏图纸内容UID与对象依赖；所有生产线宽、STB与打印需AutoCAD2027验收。

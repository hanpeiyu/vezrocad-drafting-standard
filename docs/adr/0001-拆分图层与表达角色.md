# ADR-0001 图层体系与图形表达角色解耦

- 状态：**提议（Proposed）**
- 日期：2026-11-12
- 决策：为每个对象维护稳定 `semanticId`，表达层维护 `representationRole`，再按 `viewId` 和规则映射到具体 CAD 图层；不把图层名作为唯一标识。

## 背景

原 v1 图层已体现专业分类和线宽，但复杂图块/智能墙门在一个对象内部需要主轮、细节、遮罩、填充多种表达；如果按对象×角色×视图建立图层，会出现层数量爆炸。

## 方案

- 普通简单图块 Layer 0 + ByBlock。
- 复杂图块按需要创建局部子层，角色由统一的数据契约控制。
- 颜色仅用于编辑识别和彩色出图，线宽由实体属性和图层分配。
- 黑白与彩色两份 STB 共用样式名，不重写对象线宽。

## 影响

- 正向：降低耦合、支持立面/节点/方案图切换、支持历史图层迁移。
- 风险：需要专门的遮罩/draw-order 检查，块内多层与外部参照的相互作用可能复杂。
- 回滚：保留旧 DWT 和 CTB，所有转换在副本完成。

## 待确认

在真实 AutoCAD A3 打印环境验收后，才能标记为 Accepted。

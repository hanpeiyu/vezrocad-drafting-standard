# 图框、图签与纸空间规范（V2.1 Draft）

> 原则：纸张图框和图签属于 **Layout 纸空间**；业务模型保持真实mm，不因换图幅/视口比例更改。
> 机器模板：`data/sheet-frame-templates.v2.1.json`。此处毫米数均为**示范配置**，并非国标条款或已校准打印边距。

## 四层对象

- **Paper Profile**：A3/A2/A1纸张物理尺寸、横竖向、打印设备及可打印区域；设备能力须由PC3/PDF驱动读取、实机校准。
- **Frame Template**：图纸边框、图签、修订区、说明和图例保留区、可使用的绘图区域。
- **Physical Sheet Page**：具体的Layout物理页；具有`sheetUid`、图号、图签、状态、修订，但不等同于某一张“家具平面”等图纸内容。
- **Drawing Instance**：逻辑图纸内容，如厨房北立面、全屋家具平面；可以在多张页上通过不同视口表现。

## 当前A3演示版

- 纸张实体：420×297mm，布局横向、页面1:1。
- 演示打印安全区域：从(6,6)到(414,291)，**不是默认打印机的真实可打印边距**。
- 演示图框：起点(12,12)，宽396mm，高273mm。
- 演示页脚/图签保留区：y=12～55mm；右侧图签x=286～408mm。
- 演示绘图主区：起点(18,60)，宽384、高216mm。单视口再扣除9mm标题带和上下/左右各2mm裁剪预留，实际显示窗口为**380×203mm**。
- 同类型A2/A1版式均通过独立模板指定，不允许按A3坐标直接等比放大图签、标注和纸面线宽。

## 与现有142图层对齐

| 功能 | 实际图层（复用已有定义） | 是否打印 |
|---|---|---|
| 图框边线 | `图纸-图框-边线` | 是 |
| 图签表格 | `图纸-图签-表格` | 是 |
| 图签文字 | `图纸-图签-文字` | 是 |
| 视口边界 | `图纸-视口-边界` | **否** |
| 图例线样 | `图纸-图例-线样` | 是 |

**不能把整个位于“图纸-视口-边界”层的Viewport对象理解成不打印视图内容。** 该层仅用于隐藏视口边框线，具体 CAD 行为应以 AutoCAD 2027 布局及 PDF 输出验证。

## 图签标准字段

建议固定图签属性 Tag，而不是绑定某个中文显示文字：

`PROJECT_REF`、`SHEET_TITLE`、`SHEET_NO`、`REVISION`、`ISSUE_DATE`、`DRAWN_BY`、`CHECKED_BY`、`PAPER_SIZE`、`SCALE_LABEL`、`STANDARD_VERSION`。

其他字段可扩展阶段、专业、图纸总数、企业标识和出图状态。客户地址与合同信息属于实际项目运行数据，不入当前公开规范仓库。

多比例同页时，图签比例字段统一显示“见各视口/AS SHOWN”，每个视口标题单独写1:50、1:10等，避免把两种比例错误写成一个。

## 纸空间与修订

- 页面实际打印区域由布局+PC3配置决定，要求`Plot Area=Layout`，纸面1:1，**禁用Fit to Paper**。
- 标题/图号/比例/审核人等是纸空间图签属性；视口内几何仍是模型单位。
- 图框、图签和标注不因改变模型视口比例而一同缩放。
- `sheetUid`恒定，图纸显示图号与修订号可以随编页调整；索引关联目标应使用`drawingUid`或`sheetUid`稳定引用。
- 发图前检查图幅、图签属性、图号重名、修订记录、页码与目录一致性。

## 不宣称已完成的能力

尚未提供生产DWT/图框动态块、实际纸张边距自动探测、图签字段自动回填、PDF批量验收。要先用匿名测试DWT和AutoCAD2027做 A3/A2 纸面校准，再标记正式可用。

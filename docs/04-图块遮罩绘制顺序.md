# 图块内部层级、遮罩与填充

## 三种常见误区

1. **把遮罩图层设为不打印**：WIPEOUT 若被禁打可能在打印 PDF 时失去遮挡效果。
2. **遮罩与填充视为同一物体**：HATCH 负责材料/色块表达；WIPEOUT 或背景遮罩负责剔除下方图形，两者的目标不同。
3. **只设置图层优先级就能控制叠放**：AutoCAD 中图层属性不等价于绘制顺序；`DRAWORDER`、块内部实体顺序、嵌套块和 Xref 都可能影响结果。

## 普通图块推荐模型

- 简单单角色符号（如开关插座图标）：内部几何 `0` 层 + `ByBlock`；插入到业务图层，获得统一线宽颜色。
- 复杂图块（马桶、柜体、推拉门）：图块内部角色分层。可以使用 `通用-图块-主轮`、`通用-图块-细线`、`通用-图块-遮罩`，或者专门的 `给排-洁具-遮罩`、`定制-柜体-遮罩`。**优先按可见性是否独立控制判断需要多少层。**
- 同一图块内按实体顺序：**下方底图 → 遮罩 → 填充/主轮廓 → 细线/文字**；这是绘制顺序，不是新建层的字母顺序。
- 遮罩不覆盖自己的边线；遮罩在柜体外形略内缩/匹配边界，避免浮白边；倒角、孤岛、孔洞及动态拉伸后必须回归测试。

## WIPEOUT 验证清单

- 将 `WIPEOUT` 放在 `Plot=On` 的专用层；其边框本身由 `WIPEOUTFRAME` 控制，推荐测试 `2`（可编辑但框不打印），不是把整层关闭打印。
- 单体图块、嵌套图块、动态块可见状态、拉伸和旋转、图块裁剪、Xref、多视口逐一试打。
- 使用白底/深色模型空间、彩色 STB、黑白 STB 分别验证，确认没有白框、黑块、被穿透线。
- 带透明度的 SOLID/HATCH 不能天然代替 WIPEOUT；若用背景遮罩（MTEXT 背景/多引线遮罩），另测打印驱动行为。
- 明确检查 `DRAWORDER`、`WIPEOUTFRAME`、`DRAWORDERCTL` 以及块编辑器中的保存顺序，**不要把 DRAWORDERCTL 当作打印绝对保证**。

## 智能对象动态生成

应用顺序：先几何边界 → 计算遮罩区域（考虑洞口、门缝）→ 生成图形 → 赋角色/图层 → 安排块内 draw order → 渲染检验。智能墙门交界处由业务层解决几何布尔，不依赖 WIPEOUT 凑出真实洞口。

## 典型案例

- **马桶图块**：遮罩置于洁具边线之下、瓷砖缝之上；保留外轮廓和水箱分界。
- **推拉门**：轨迹/口袋门表达按可见性决定是否盖住墙线，不能让整块遮罩消去结构轮廓。
- **衣柜**：平面柜体遮住底部铺贴纹理，但不消除必须显示的墙体边界；立面图使用不同视图，不依赖在同一个块里堆更多遮罩。

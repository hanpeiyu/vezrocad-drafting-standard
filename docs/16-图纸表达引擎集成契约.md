# 专业图纸表达引擎：与 VezroCAD 插件协作契约（提案）
> 本仓库只保存规范/数据/验证；不直接修改 VezroCAD G1 内核。可先做适配层原型。

## 分层职责
1. **业务层**：墙、门窗、柜体、吊顶、灯具、机电智能族，拥有 semanticId 和真实几何。
2. **表达解析层**：依据 viewId、representationRole、paperSize、viewportScale、outputMode 选择显示实体、遮罩、图层、线宽和绘制顺序。
3. **CAD 执行层**：创建需要的层、设置 ByLayer、VP Lineweight / VP Plot Style、安排块内外 DRAWORDER、应用页面设置。
4. **审计层**：不改DWG即可报告未知图层、未知样式、Normal漏彩、显式对象线宽、遮罩风险、规则环和缺少比例预设。

## 输入/输出最小契约
输入字段：drawingId、layoutId、viewportId、viewId、paperId、scaleDenominator、outputMode、profileVersion、options.dryRun。
对象字段：semanticId、objectId、representationRole、hostRelationship、geometryRef；不得用中文图层名作为唯一 ID。
输出字段：resolvedStyleName、effectiveLineweightMm、targetLayer、drawOrderEdges、visibility、warnings、requiredManualReview。
约束：preview/dryRun 优先；apply 必须在 DWG 事务内可回滚，绝不覆盖原始统帅 DWT、CTB 或生产项目图纸。

## 规则优先级（待 ADR）
构件语义与几何真实关系 > 视图特定表达角色 > 用户显式审查后的覆盖 > 纸面线宽与配色预设 > 安全默认。
所有临时覆盖均有范围与来源；不同视口可共享模型但采用不同表现，不复制同一墙体几何。

## 先做一个极小原型
只在一份匿名测试图中完成：家具平面 1:50 + 柜体节点 1:10、马桶和衣柜遮罩、A3 GRAY/COLOR预览审计报告。
未生成的 STB 先只渲染模拟预览或给出缺失诊断，不能点击出正式 PDF。所有操作应保证 CAD 对象可编辑、撤销/重做有效。

## 与 G1 约定
只保留 IRepresentationResolver、IViewProfileProvider、IPlotProfileProvider、IDrawOrderPlanner 等接口概念，名称仅是提案，不要求此时实现或更改现有 CONTRACT-01。
当 ADR 被接受并完成 AutoCAD 2027 实机验收后，才决定插件侧具体类、接口和开发顺序。

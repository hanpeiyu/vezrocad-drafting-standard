# 规范管理页面与插件调用设计（V2.1 提案）

> 管理器不是一个普通CAD图层管理器，而是家装图纸“图层、表达、图纸套、线宽、打印和关联”的统一配置工作台。
> 管理页面定义：`data/admin-workspace.v2.1.json`。

## 页面模块

1. **规范版本总览**：当前使用的已发布版本、草稿变更、Git提交、规则健康度、实机验收状态。
2. **图纸目录管理**：9专业组/37图纸类型，条件触发规则，自动出图包；查看每种图纸的重点、背景和隐藏构件。
3. **图层与表达角色**：图层中文名、稳定ID、对象语义标签、13种轮廓/细节/遮罩角色、图块内外排序。
4. **纸张与比例适配**：选A3/A2/A1、读取实际图形范围、动态计算净空间、给出纸张成本优先/可读性优先的多个方案，并预览是否需要拆图。
5. **图框、图签与视口排版**：编辑图框打印安全区、图签属性、纸空间视口槽位；支持一纸多视口、多比例、视口锁定和碰撞检查。
6. **彩色和黑白出图**：使用屏幕配色、STB目标样式名、线宽预设、不同专业图纸的默认模式；检测Normal/TrueColor等漏彩。
7. **依赖影响分析**：当衣柜位置改变，查看关联的家具平面、柜体立面、插座、施工节点，并提醒需要复核的项目。
8. **审核与发布**：预览变更前后，检测无效规则、循环遮挡、缺少STB/线宽、导出规范PR和快照；审核后才允许切到生产配置。

## 图纸表达管理器的一个典型动作

设计师打开一张超长户型的家装家具平面。管理器读取本图需表达的构件外包框，显示：

- 首选：A3 / 1:50；实际超出图框净区。
- 推荐多个候选：A3 / 1:75（省纸优先），A2 / 1:50（可读性优先），或A3 / 1:50 + 分区节点图；必须按当前图框槽位、标题带和真实注释范围重新计算。
- 用户选择后，在该布局的视口设置相应比例和VP Lineweight；模型里墙体、门窗、柜体的实际几何不变。
- 同一页可以多视口，主平面和节点各自采用合适的线宽预设与LOD。
- 设定打印颜色：BW / GRAY / COLOR / PRESENTATION；未验证V2.1二进制STB时仅展示配置目标，不能声称已可打印。

## UI、后端和插件边界

前端可复用React+TS并嵌入CAD WebView2，也可在本机浏览器独立运行。编辑数据库由本地.NET管理服务统一负责事务、外键、审计与导出。

插件正式使用只需要带版本的不可变规范快照和已打包的合格STB，无需管理页面常驻、无需联网，也无需实时查询管理SQLite。

管理页面的草稿修改**不能立即修改生产DWG**；先预览、校验并经用户明确选择“应用”后，才由CAD事务执行。应用失败应回滚，保留原有图层与CAD对象。

## 建议的迭代阶段

- M0：确认管理页面字段、身份体系和关系库边界；只有设计文档和SQL样例。
- M1：本地可读SQLite + Git JSON导入，做关联查询、校验和只读管理页。
- M2：编辑草稿、差异预览、自动检测及导出PR；不允许在插件中直接发布未经审核的规范。
- M3：WebView2插件侧预览当前图纸表达；只读运行与CAD实机线宽/遮罩验收。
- M4：提供可回滚、可撤销的正式应用能力和项目影响分析。

不建议现在重构VezroCAD G1。先用独立仓库确认契约、最小数据库及管理页面原型，再分配多Agent开发。

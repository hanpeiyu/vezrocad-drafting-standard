# V2.1 图纸套样例与自动审计

> 命令：`python scripts/compile_sheetset.py`。
> 只会在标准输出显示建议图纸目录及诊断，不会操作 DWG、STB、PDF 或 VezroCAD 插件。

## 样例工程

`examples/sheetset-project.v2.1.example.json` 模拟一个有拆墙、新建墙、地面铺装、吊顶、定制柜、强弱电和冷热水改造，同时安装暖气片、但没有空调新风及地暖的家装项目。

运行：

```bash
python scripts/validate_sheet_system.py
python scripts/compile_sheetset.py
python scripts/compile_sheetset.py --output sheetset-dryrun.json
```

编译结果包含：

- 每张实例的稳定 `sheetTypeId`、实例 ID、分组、房间/柜体/节点引用。
- 当前图纸的重点和背景语义、基础视图类型。
- A3 出图比例、对应 VP Lineweight 配置、建议输出模式、V2.1目标STB文件名。
- 人工剔除原因、缺少引用、未验证 STB、需要专业人员校核等诊断。

## 为什么不自动把这些图都出出来？

目前图纸套和表达规则是**规范元数据**，不等于建筑测量已校准、对象三维/二维几何真实、图框编页和相关构造已深化。

编译器故意将 `productionReady` 设为 `false`：任何未认证的 STB、缺少实例引用或专业审核项，均不能冒充施工图正式输出。实际自动绘制需要另行开发 VezroCAD 对应执行适配器、调度器与用户确认流程。

## 未来最有价值的能力

- 项目改造范围变更后，自动提示增删受影响的图纸；
- 一个房间的新柜体改变尺寸时，提醒家具平面、柜体立面、插座定位与局部节点检查；
- 同一个原始建筑模型支持拆改、布置、地面、顶面、机电的不同表达预设；
- 一键出 A3 黑白/灰阶/专业彩色 PDF 套图，带统一图名、页码、索引与校核报告；
- 生成目录时使用真正存在的图纸实例，而不是每次机械列出37种类型。

建议先完成“图纸套目录 + 显示矩阵”验收，再推进全自动立面和机电输出。

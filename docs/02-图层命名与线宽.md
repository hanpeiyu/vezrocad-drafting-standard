# 中文图层命名与 A3 线宽

## 命名

**格式：** `专业-对象-表达-状态`，根据需要使用 2～5 段；每段建议 1～3 个汉字。状态在末尾，不让“现状/新建/拆除”和“方案/施工”等含义挤在同一个字段。

- `建筑-墙体-轮廓-现状`、`建筑-门体-细节`、`定制-柜门-细节`、`通用-图块-遮罩`。
- 特别说明：系统层 `0`、`Defpoints` 以及既有 `BS-*` 等历史层作为软件/迁移例外，不强制混改。
- 属性字段 `默认表达角色` 是智能构件映射的默认值，不阻止实例视图再细分。

## A3 纸面线宽建议（单位毫米，非模型单位）

| 粗细 | 常用线宽 | 场景 |
|---|---|---|
| 剖切粗 | 0.50 / 0.53 | 墙体、柱与重点剖切边 |
| 主轮廓 | 0.35 | 门窗柜体主要外轮廓、立面近景 |
| 次轮廓 | 0.25 | 门扇边、设备、柜体内部结构 |
| 常规细线 | 0.18 / 0.20 | 文字引出、构造层分隔 |
| 细节 | 0.15 | 家具内部、开启弧、砖缝、定位尺寸 |
| 最细 | 0.13 | 填充、弱投影；在低分辨率打印机需验收 |

这是项目默认**建议值**，非 GB/T 50001 的唯一指定线宽表。若同一张图有多个比例，严格按**纸面视觉层级**决定，不要在 STB 内再次变更线宽。

## 颜色

颜色按专业/状态便于辨识；选 ACI 索引色保持 STB 黑白行为更易预测；在彩色输出中可区分新建/拆除/暖通与电气；**不可只靠颜色表达拆除与新建**，线型、图例、注释应构成冗余。

## 图层控制原则

- 默认图元 ByLayer；简单单角色符号可用 Layer 0 + ByBlock。
- `Plot=Off` 仅用于真正不应出图的辅助对象/视口边界，不可用于 WIPEOUT 遮罩。
- 同名图层不得在不同工程模板中被赋予互不兼容的用途，变更须发 ADR。
- 交付外部单位可映射目标规范，禁止直接用重命名破坏 SmartCAD 语义。

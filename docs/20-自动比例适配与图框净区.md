# 自适应图纸比例与版面净空规则（V2.1 提案）

> 不再把“家具平面=A3 1:50”作为固定约束：1:50 是优先比例，实际是否放得下由当前图纸内容与图框可用净空决定。
> 数据：`data/paper-fit-layouts.v2.1.json`、`data/auto-scale-policies.v2.1.json`、`examples/scale-fit-cases.v2.1.json`。
> 示例工具：`python scripts/resolve_scale_fit.py --view plan-furniture --width-mm 24000 --height-mm 12000`。

## 计算方法

每张图纸的图形应由 **当前图纸实例、当前视图的真实外包框 + 必须显示的标注区 + 可能的旋转** 组成，而不是对整个 DWG 的所有对象计算 EXTENTS。

若图形实际宽高为 `W_model`、`H_model`（单位mm），比例是 1:n，纸面图形尺寸为：

`W_paper = W_model / n + AnnotationReserveX`；
`H_paper = H_model / n + AnnotationReserveY`。

必须同时满足：

`W_paper <= UsableViewportWidth`；`H_paper <= UsableViewportHeight`。

所以最小理论比例分母是 `n_min = max(W_model / W_usable, H_model / H_usable)`；但实际应该在经团队确认的离散比例候选集中选取，比如 1:50、1:75、1:100，而非随意产生 1:66.7。

**重要：** A3 实际纸张420×297mm，不代表绘图区有420×297mm。旧版`resolve_scale_fit.py`仍作为历史数学试算样例，使用360×240mm；而**当前图纸套编译器已改用新版`plan_sheet_layout.py`**，从具体图框/图签/视口槽位计算A3-SINGLE净区**380×203mm**。旧版算法不再作为图纸套生成器的决策来源。正式应用仍需获取真实打印机可打印范围。

## 同一幅面下按户型试配

| 实际平面范围 | 新版 A3-SINGLE 内容净区380×203mm | 建议 |
|---|---|---|
| 12m×9m | 1:50 可容纳 | 首选 1:50 |
| 18m×12m | 1:50高度溢出 | A3 1:75或A2 1:50 |
| 24m×12m | 1:50 放不下 | 选 1:75，若当地/企业标准不接受则 A2或分区 |
| 35m×20m | 1:100 可容纳 | 选 1:100；若细节稀疏可加放大图 |
| 50m×30m | A3 1:100也放不下 | 可试 A2/1:100 或拆图，真实标注另验收 |

> `1:75` 是项目提案的可选比例，不声明为任何国标对全部室内施工图的强制推荐比例。最终许可比例要进入公司配置并试打审查。

## 真实策略

1. 从图纸类型获取首选比例与可选比例清单。
2. 读取具体图纸实例的DWG外包框、房间/楼层边界、保留文字和标注空间。
3. 计算横向放置及获准的90°旋转；旋转必须审核指北与文字方向。
4. 优先当前幅面和较高可读性；如放不下，可按策略允许更大纸张。
5. 依然放不下则建议“全屋总图 + 局部放大图”或按房间/楼层分图，不得无上限缩小。
6. 单张纸可有1:50平面与1:10节点两个视口，各自采用独立的VP Lineweight预设。
7. 若用户锁定了比例，系统只能显示溢出诊断和可选方案，不得默默修改。
8. DWG模型几何、真实尺寸、智能对象参数不因比例或排版调整。

**必须区别两种状态：** `fit-suggested` 仅表示对输入的示例外包框和净区做数学试配；`AutoCAD实际通过` 必须由CAD真实图框和PDF实机检查后单独记录。若未输入真实外包框，当前图纸的首选比例只能标为“尚未验证放得下”。

## 与制图系统的关联

项目范围 → 图纸实例 → 图形/标注包络范围 → 自动选比例/选纸张 → 视口配置 → 对应纸面线宽预设 → 彩色/黑白STB → 校验输出。

管理页面可允许用户手工修改可用净区、候选比例、优先A3、允许A2和是否强制分区。比例适配是 **纸面排版问题**，线宽由表达角色和最终视口比例另行决定。

## 与新版图框与视口算法的过渡

`resolve_scale_fit.py`仅保留为旧算法对照；**当前`compile_sheetset.py`已调用`plan_sheet_layout.py`**，统一按图框/布局/视口标题带进行纸面数学试配。它可以对比A3 1:75与A2 1:50，且支持设计师锁定比例后的溢出诊断。但这仍是dry-run，尚未形成AutoCAD真实页面生成、标注碰撞检查和正式`PresentationPlan`执行器，不得直接应用到生产DWG。

参见[图框图签纸空间规范](23-图框图签纸空间规范.md)、[图纸布局视口规范](24-图纸布局视口规范.md)。

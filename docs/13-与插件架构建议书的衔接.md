# 与插件《智能对象与多视图表达系统》架构建议书的衔接

> 建议书（DocId `QA-REP-ARCH`，v0.1，[PROPOSED]）属于 **VezroCAD 插件仓库**，不在本仓库保存。本文只记录两边的接口约定。
> 本仓库只提供**数据标准**：表达角色、图层、视图模板、STB。插件内部的 Anchor、Representation 缓存、剖切/遮挡解析不在这里定义。

## 职责分工

| 插件侧（建议书） | 本仓库 |
|---|---|
| SmartFamily 业务语义 | 业务语义 ID（`wall.new` 等） |
| Representation：表达语义（Cut / Visible / Hidden…） | 表达角色（`CUT_HEAVY` 等）与样式 |
| ViewContext（ViewType / Discipline / Phase / DetailLevel / OutputProfile） | 视图模板 `view-presets.json` |
| Drawing/Output：图层、线宽、STB | 图层目录、STB、打印验收 |

## 两层词汇：语义 → 角色 → 图层

- **表达语义**回答“这条线在该视图里是什么”（可见性语义）；**表达角色**回答“画成什么样”（线宽、线型、STB 样式）。
- 映射表：[`../data/semantic-to-role.json`](../data/semantic-to-role.json)，由 `scripts/validate.py` 校验目标角色存在。
- 同一语义在不同视图可映射到不同角色，例如精细程度更高时 `Visible` 的内部线降为 `DETAIL_THIN`；该规则由视图模板携带，不写进族。

## 约定

1. **常规遮挡默认省略不可见轮廓**。`HIDDEN_DASHED` 仅在图纸明确要求（给排水安装、检修、人工指定关系图）时使用，不是默认输出。
2. 优先级：当前视图局部人工覆盖 > 图纸/视口模板 > 专业表达规范 > 族默认。表达覆盖不得改变尺寸、开向、标高、施工阶段与连接关系；覆盖必须进入检查报告。
3. “同一实例在两个视口用不同表达”是目标能力，**尚未验证**，见验收项 A18。
4. 派生表达是缓存，不是语义真相；出图时 Dirty/Failed 状态应有可见告警（插件侧职责）。

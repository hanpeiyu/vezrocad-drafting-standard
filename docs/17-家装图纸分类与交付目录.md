# 家装工程图纸分类与交付目录系统（V2.1 提案）

> 这里的 37 种类型是 **项目可配置图纸目录**，不是国家标准规定的统一强制清单，更不代表所有家装项目必须输出37张。
> 数据源：`data/sheet-taxonomy.v2.1.json`，以及 `data/sheetset-presets.v2.1.json`。

## 分级结构

**项目 → 图纸套 → 专业图纸组 → 图纸类型 → 图纸实例 → 视口/图形表达**。

- `sheetTypeId`：稳定图纸类型标识，如 `ELE-POWER`；不随中文图名、图号改变。
- `sheetInstanceId`：具体图纸实例，例如某一房间的北立面。一个图纸类型可能有多张实例。
- `baseViewPresetId`：复用 V2.0 的九套基础视图模板；同一模板可用于多个图纸类型，各自配置不同关注信息。
- `projectFeature`：真实工程内容开关，如是否做吊顶、是否更换墙面饰面、是否涉及强弱电改动。默认关闭不自动生成不相关图纸。
- `required/feature/optional`：本项目中的 core/feature/optional 表示 **推荐基准 / 实际工程触发 / 手动选择**，不是法定义务或设计交付充分性声明。

### 常用单项图纸

- **原始测量**：原始结构、墙厚、门窗与量房尺寸。严禁从设计方案倒推原始测量值。
- **拆改图**：保留/拆除/新建状态必须同时通过线型、图例、文字表达，彩色打印只是辅助。
- **平面布置图**：突出家具、柜体、门洞关系和必要墙线，不显示无关电路或铺贴细缝。
- **地面铺装**：重点是材料、分格、起铺点、收口、标高；家具仅按定位参照、需要时低对比度显示。
- **顶面**：吊顶造型和标高、灯位定位、空调回风或检修口，允许将灯位与吊顶尺寸拆成不同图纸。
- **强电插座**：突出设备、插座、安装标高和定位尺寸；墙体家具仅背景参照。
- **弱电**：网络、电视、信息点；不能把弱电设备作为普通强电插座处理。
- **灯具与开关**：灯位图表达天花点位，开关控制图表达逻辑关系，不等于实际线缆敷设路线。
- **给排水**：冷热水、排水、洁具，必要时拆多张，专业颜色配合文字图例。
- **立面/节点**：按房间、墙面或柜体实例重复，不预先把所有墙的立面都机械输出。

## 图纸清单是“条件集合”，不是固定列表

完整家装建议基准包包括封面、目录、通用说明、原始测量、平面布置、家具尺寸定位与立面索引；墙体拆改、吊顶、地坪、强弱电、暖通与定制柜等只由真实项目特征触发。

`full-renovation`、`partial-renovation`、`concept` 是三种初始图纸套模板。其中方案展示图包 **不能当作完整施工图交付**。特殊事项需要增补或删减图纸的，应记录理由并由设计师审核。

**图号不等于图纸类型 ID**：最终 A3 编页须依据实际生成的图纸实例、项目空间与图纸分组，而不是对37种固定列表排序。

## 专业设计审核边界

- 配电回路、空调/新风、采暖等可能需要专业计算及复核，规范可以提示依赖关系，但不能代替合格专业人员的技术校核。
- 现场承重、燃气、防水、楼板、结构等项目不能用插件的自动图纸目录判定合法可施工。
- 本目录不能承诺包含所有主管部门或企业要求的交付内容，交付范围仍由项目、合同、当地规范及专业设计决定。

## 后续扩展

按项目阶段（量房/方案/深化/施工/竣工）和房间范围选择图纸实例；为不同企业增补图纸类型、图名和纸张编号规则；系统对人工删除的必要项提出提示，而不秘密替用户决定。

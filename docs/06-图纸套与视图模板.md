# 图纸套与视图模板

不要为平面图、地面图、插座图、立面图分别复制同一套建筑几何。`data/view-presets.json` 是**提案配置，不是已经接入的 CAD 插件**。

| 视图 ID | 典型输出 |
|---|---|
| `plan-existing` | 原始结构/量房 |
| `plan-demolition` | 拆除新建、开洞封洞 |
| `plan-furniture` | 家具平面/定制柜 |
| `plan-floor` | 地面铺装/起铺点 |
| `plan-ceiling` | 顶面/灯位 |
| `plan-electrical` | 强弱电点位 |
| `plan-plumbing` | 冷热水、排水 |
| `elevation` | 室内立面及定制柜立面 |
| `detail` | 剖面与节点 |

## 智能视口规则

1. 以图纸套 `viewId` 决定哪些业务对象、图形角色可见；再解析为图层冻结或打印样式覆盖。
2. 同一层的对象如需不同显示强度（例：电气图中的家具和电气设备），应考虑**视口覆盖、表示代理或不同表达层**，不可直接修改底层对象属性。
3. 在未来 G1 智能视口中留出模板继承、范围和新图层规则：新建符合条件的图层可自动继承视图规则。
4. 视图标注/图名/图框在纸空间集中管理，立面与平面共用业务源但不必共用一个渲染块定义。

## A3 与纸张适配

图层与表达角色不可依赖 A3 绝对尺寸。未来加入 A2/A1 配置时，优先通过视图比例和标注尺寸适配，不改变所有实体颜色和语义。

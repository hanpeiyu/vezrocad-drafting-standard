# 总体架构：业务语义 ≠ 图形表达 ≠ 图层 ≠ 视图 ≠ 出图样式

## 五个维度

| 维度 | 稳定标识 | 用途 | 不该承担 |
|---|---|---|---|
| 业务语义 | `wall.new`、`cabinet.wardrobe` | 是什么对象、有何参数 | 不存在线宽或纸张属性 |
| 表达角色 | `CUT_HEAVY`、`DETAIL_THIN`、`WIPEOUT_MASK` | 画哪些边、用什么形态 | 不作为对象身份 |
| CAD 图层 | `建筑-墙体-轮廓-新建` | 实体分组、可见、图层默认线宽/颜色 | 不作为唯一语义 ID |
| 图纸视图 | `plan-furniture`、`elevation` | 哪些对象/角色显示及简化 | 不复制 DWG 业务对象 |
| 输出模式 | `VZ-A3-BW.stb` 等 | 按纸张输出黑白/彩色 | 不覆盖线宽与线型 |

示例：衣柜对象拥有 `cabinet.wardrobe`、尺寸/柜门状态等业务参数；平面图映射轮廓、柜门细线和遮罩；立面图映射门缝、拉手、层板虚线、剖面填充。未来支持不同公司图层模板，但不改变智能对象。

## 作用域与优先级

- **默认**：ByLayer 控制线宽/线型/颜色。简单单角色图块可由插入实例通过 Layer 0 + ByBlock 继承。
- **复合图块**：内部线条按表达角色映射专用图层。并非每个族都建立七个子层；只有需要独立开关/打印/遮罩控制的角色才建立。
- **实例异常覆盖**：必须进入检查报告；不得靠“一键全设 ByLayer”破坏合法的内部表现。
- **SmartCAD**：在 G1 公共契约中先约定 `semanticId`, `representationRole`, `viewId`, `layerRuleId`；实现渲染及迁移可后置。

## 必须考虑的构件族

智能墙、门（平开、推拉、口袋门、隐形门）、窗、柜体、地面铺贴、顶棚、灯具、开关插座、给排水、空调/新风/地暖/暖气片、洁具、家具、立面与节点对象。

## 性能

- 智能对象内部不要每一次再生都全量扫描整个 DWG 的 100+ 图层；使用稳定键索引+懒创建。
- 同一角色映射应缓存，失效条件为模板变更/对象状态变更/视图切换。
- 避免为每种视图重复实体及重复遮罩。图层表示是技术实现，不是业务数据源。

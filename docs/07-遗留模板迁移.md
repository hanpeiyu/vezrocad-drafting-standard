# 历史统帅/类 DOP 模板兼容

源文件：用户提供统帅模拟 DOP 的 `.ctb` 和 `.dwt`。已知原 CTB 以 ACI 颜色控制打印线宽，曾经读取出较多 0.13mm 对应项。**目前尚未可靠提取原 DWT 的完整 LAYER 表**；本仓库图层名是重新设计，不冒充原统帅/DOP 真实图层清单。

## 安全原则

- 原始统帅 CTB / DWT 及含客户数据的 DWG **不入库**；尤其公开仓库不得包含这类来源不明的商业模板。
- 旧图纸绝不强制原地重命名；新层与旧层可以并存，通过透明的映射规则过渡。
- `BS-墙`、`FF-*` 仅已知为历史用法示例，具体语义应经样本图纸核实，绝不靠前缀猜测对应新建/拆除状态。
- 同一项目中尽量固定图层模板和打印样式；迁移通过导出副本测试，维持客户实际交付稳定。

## 推荐迁移步骤

1. 在 AutoCAD 内备份 DWT，导出原始图层清单（可用 DXF R2018 或 Data Extraction 等）及一张原纸面 PDF。
2. 保存原层名、ACI、线宽、线型、是否打印、嵌套块特例；建立**有人工审核**的 `legacy-to-v2` 映射表。
3. 对 CTB 模式图纸，先在**副本**使用 AutoCAD 官方 CTB/STB 转换流程，不能直接选择 STB；检查 `PSTYLEMODE=0`。
4. 逐图纸套对比 BW/COLOR PDF（遮罩、宽度、字体、尺寸、填充）。
5. 只有通过验收才选择将个别图层规范化；出现冲突保留原始内容并记录例外。

## 未决

- 原厂 DOP 标准文本未随本次输入提供；只能借鉴上传样图和 CTB，不能宣称完全符合 DOP。

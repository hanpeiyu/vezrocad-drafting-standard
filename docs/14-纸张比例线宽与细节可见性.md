# V2.1 纸张、比例、线宽和细节可见性
> 机器配置：data/lineweight-profiles.v2.1.json 和 data/detail-visibility-policy.v2.1.json。参数均为待试打建议值。

## 四个变量不能混用
- 物理模型实际尺寸（mm）：构件真实几何，不因出图比例改变。
- 视口比例（1:n）：决定几何在纸上呈现的尺寸。
- 纸面线宽（mm）：应按视觉层级的离散预设选用，不把模型几何尺寸直接当作笔宽。
- 纸面可见细节：以实际间距 / n 计算；小到看不清的非关键细节可以简化，但不能删除原数据。

## A3建议表（纸面毫米）
| 视图比例 | 剖切粗线 | 主轮廓 | 次轮廓 | 细节 |
|---|---:|---:|---:|---:|
| 1:100 | 0.35 | 0.25 | 0.18 | 0.13 |
| 1:75 | 0.40 | 0.30 | 0.20 | 0.13 |
| 1:50 | 0.50 | 0.35 | 0.25 | 0.15 |
| 1:25 / 1:20 | 0.50 | 0.35 | 0.25 | 0.18 |
| 1:10 | 0.60 | 0.40 | 0.30 | 0.18 |
| 1:5 | 0.70 | 0.50 | 0.35 | 0.20 |

上述只是建议初值，A2/A1 可以单独维护图幅预设，但**不应简单因纸张更大就把线宽整体乘以系数**。一个布局允许多个视口（例如全屋 1:50、节点 1:10），分别应用各自预设。

## CAD 实施顺序
优先：实体 ByLayer → 视口 VP Lineweight 覆盖 → STB 统一 Use Object Lineweight。只有需要不同表达角色的构件才能通过图层细分/视图代理分别赋宽。
禁止：为了切换打印比例而改写几何、对全局图层做破坏性替换、开启 Scale Lineweights 使全图粗细不可预测。
注意：实体已显式设置了线宽时，视口图层覆盖不一定生效；需要属性审计，而不是强行清空用户合法覆盖。

## 基于实际尺寸的细节决策
纸面特征尺寸 = 模型特征尺寸 / 视口比例分母。例如实际20mm的两条分缝：1:20是1.0mm；1:50是0.4mm；1:100是0.2mm。
- 小于0.30mm：建议隐藏/合并**非关键**细节。
- 0.30–0.60mm：可换细线或适当减少细节密度。
- 大于等于0.60mm：通常可以保留。
这些阈值不是强制国标。剖切、尺寸、必须施工识别的信息和涉及安全的构件符号不得自动隐藏。

## AutoCAD注意事项
使用纸空间1:1打印；视口比例1:n；检查 PSTYLEMODE=0、视口覆盖开关、注释性对象和纸面字体高度。线宽以 PDF 和实物纸张为最终验收，而不是屏幕视觉。

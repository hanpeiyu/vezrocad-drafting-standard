# A3 + STB 出图模式（颜色与线宽解耦）

## 核心承诺

- 实体线宽来自图层或必要时对象自身。**STB 中 Lineweight = Use Object Lineweight**。
- 两个同名样式集合：`VZ-A3-BW.stb` 用黑色/不同筛选浓度输出；`VZ-A3-COLOR.stb` 使用对象颜色。彩色与黑白**不改变 DWG 图层/实体属性**。
- 彩色和黑白中的 `VZ-MASK` 都使用**对象颜色**，只用于 WIPEOUT；其实际打印表现需要按 CAD 和 PDF 驱动验收，不能假定所有遮罩都适用黑色覆盖。

| 样式 | 黑白筛选 | 彩色筛选 | BW 输出色 | 两版线宽 |
|---|---:|---:|---|---|
| `VZ-MAIN` | 100% | 100% | 黑 | 对象线宽 |
| `VZ-SOFT` | 80% | 90% | 黑/灰阶 | 对象线宽 |
| `VZ-FAINT` | 45% | 65% | 黑/灰阶 | 对象线宽 |
| `VZ-FILL` | 25% | 45% | 黑/灰阶 | 对象线宽 |
| `VZ-ACCENT` | 100% | 100% | 黑 | 对象线宽 |
| `VZ-MASK` | 100% | 100% | 对象色（仅遮罩） | 对象线宽 |

## 真实限制

- `Normal` 样式**不能通过这两份 STB 覆写为黑色**。有色实体/图层如果保持 Normal，会在 BW 中漏彩色。插件应扫描并报警。
- `TrueColor`、Xref、嵌套块、显式对象样式覆盖、视觉样式/阴影打印可能产生特殊结果，必须试打；黑白打印排障可参见 Autodesk 官方文档。
- 图层 `Plot=Off` 与 STB 无关；用在辅助层，不用于 WIPEOUT。
- 两套 STB 目前通过编码和读回测试，**未在 AutoCAD 2027 完成真实 PDF/纸张验收**。

## A3 默认页设置

- A3 横向 420 × 297 mm，布局按纸面 1:1；模型单位 mm，模型实物 1:1。
- 全屋 1:50 优先；大户型改 1:75 / 1:100 或分区；柜体立面 1:20 / 1:25，节点 1:10 / 1:5。
- 页面设置建议 `A3-施工图-黑白`、`A3-施工图-彩色`，打印机优先经验证的 DWG To PDF.pc3。
- 勾选使用打印样式和打印对象线宽；按需要开启透明度打印；检查打印区域边距、中心、线宽缩放、打印驱动。
- 纸面文字常用 2.5~3.0 mm，图名 4~5 mm，可视具体字体、打印机调节。

## 试打印样张

至少同一 A3 页面放：新旧墙/拆墙、开门弧、马桶遮罩、柜体细线、地砖 600×1200 缝、灯位、虚线投影、0.13～0.53 线宽阶梯、填色、中文标注、带 TrueColor 测试对象。BW 和 COLOR 分别 PDF 输出，**必须确认换 STB 前后线宽不变**。

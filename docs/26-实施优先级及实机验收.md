# V2.1 核心优化顺序与AutoCAD2027验收用例

## P0：先完成的公共契约

- [x] 图框、图签、纸空间及视口槽位的机器配置（**提案值**）。
- [x] 逻辑图纸内容 `drawingUid`、实体纸张页 `sheetUid`、视口 `viewportUid` 明确分离。
- [x] 多图幅候选比例方案评分，演示A3/1:75与A2/1:50之间的选择。
- [x] 标准SQL增加图框/版面/视口表，项目索引库单独建模；已发布版本用数据库触发器禁止直接修改。
- [ ] 完整的`PresentationPlan`规则编译内核及可解释诊断，并通过跨模块一致性测试。
- [ ] 真实DWT图签与AutoCAD2027图框净区/打印机边距获取。
- [ ] STB V2.1四套文件生成及CAD实际打印测试。

## P1：先做管理页面的三个最小工作区

1. **专业图纸表达矩阵**：选择37种图纸类型，能看到FOCUS/CONTEXT/HIDE及其对应图层角色。
2. **图框/视口排版**：从真实DWG获取图形包络，显示A3/A2方案；允许选择主图+详图、两个立面等组合。
3. **规则差异与诊断**：查看草稿版本变更、规则来源、未解析图层、版面碰撞和未验证STB。

页面可以用React/TS+WebView2，同时具备不接CAD的只读预览模式；先完成只读，再开放草稿编辑。不要为了管理规范而让CAD操作实时依赖数据库连接。

## P2：图纸依赖、自动排版和打印流水线

- 智能墙/门/衣柜/机电对象更新后，按`drawingUid`追踪所有视口放置；分清自动更新、需重生成及人工复核。
- 文字标注碰撞、纸面图名避让、非矩形视口/布局空间优化、目录索引与自动编页。
- 经过AutoCAD 2027 A3/A2打印校验后才允许生产出图。

## 实机验收矩阵（新项）

| 编号 | 情况 | 判定 |
|---|---|---|
| F01 | A3图框及真实打印机净区 | 边框、图签不被裁切 |
| F02 | 单主视口和主图+节点 | 视口标题、图签、图例互不覆盖 |
| F03 | 同页1:50 + 1:10 | 各自VP线宽、注释比例正确 |
| F04 | A3 1:75 vs A2 1:50 | 能给出两方案并显示适配原因 |
| F05 | 视口锁定 | 滚轮缩放不破坏已确认比例 |
| F06 | 视口边框非打印 | 内容仍正常打印、边框线不出纸 |
| F07 | 多页换序/插页 | 逻辑图纸、索引和对象依赖不丢失 |
| F08 | 门窗/柜体/插座联动 | 自动更新与人工复核正确区分 |
| F09 | 修改图签和修订 | 真实纸面页的UID不因显示图号变化 |
| F10 | 改变STB颜色模式 | 同样纸面线宽、图层颜色不被改写 |
| F11 | 嵌套/动态块遮罩 | 不遮住必需墙体边线与尺寸 |
| F12 | Git规范版本回滚 | 标准快照匹配，旧DWG不强制迁移 |

自动CI验证的只是JSON/DDL、排序几何和逻辑身份；以上F01-F12仍需要AutoCAD实机测试。

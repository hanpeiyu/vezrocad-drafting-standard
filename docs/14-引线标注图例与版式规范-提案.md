# 引线标注图例与版式规范（提案）

> **规范编号** VZ-ANNO-01 · **状态** [PROPOSED]，图块与 AutoCAD 2027 实机验证 [SPIKE] · **版本** v0.1（2026-11-17） · **适用** 室内装修施工图：拆改、家具、地面、顶棚、立面、机电、节点

## 1. 定位、依据与边界

- 本文是 VezroCAD 的**可编辑制图样式规范**，不承担 CAD 插件的算法或存储实现；插件侧开发说明由私有仓库 VezroCAD 的 `docs/smartcad/03-representation/annotation-system-proposal.md` 维护。
- 参照本仓库 [标准依据与边界](10-标准依据与边界.md) 所列的 GB/T 50001-2017、JGJ/T 244-2011，并参考典型室内施工图惯例。**本文的组合框造型、缩写、建议尺寸、角度与算法要求均为 VezroCAD 提案，不宣称为国家标准统一规定。**
- 以现有常规 CAD 图块和普通 DWG 工作流为首期对象；无须依赖智能墙、智能家具或轻量 BIM。
- 不复制或公开上传第三方设计公司受限制的商业图块、CAD 模板、客户图纸。后续用户现用图例 DWG 仅在取得授权后抽取参数，按原创样式重绘。
- 设计原则：**内容字段 / 标注外观 / 引线与锚点 / 版面排布**四部分独立，便于扩展和替换。

## 2. 应用场景与建议模板

| 场景 | 例文或字段 | 首选母版 | 补充 |
| --- | --- | --- | --- |
| 拆除 | 拆除原有非承重隔墙 | A 文字引线 | 可无块；不自动推断墙体性质 |
| 新建 | 新建100厚轻质隔墙 | A 文字引线 | 文案由用户确认 |
| 家具 / 软装 | FF01 / 扶手椅 | B 编号名称 | 编号可复用，不等于实例序号 |
| 地面铺贴 | WF01 / 多层实木地板、规格 | C 材料标签 | 支持 CT、ST、WF |
| 顶棚 / 天花 | CH 2.600 / PT01 / 乳胶漆饰面 | D 标高材料组合 | 标高及其基准、单位均可配置 |
| 立面饰面 | WD01 / 木饰面；PT01 / 乳胶漆 | C 材料标签 | 可附规格、工艺 |
| 收口与节点 | MT05 / 金属收边；详图编号 | C 或 E 索引符号 | 索引标记独立于材料标签 |
| 灯具、风口、插座等 | 插座 / 安装高度 / 特殊要求 | F 设备点位 | 原有符号图例与文字引线组合 |
| 施工工艺说明 | 防水翻边、墙面基层处理 | A 文字引线 | 多行正文、可手动编辑 |

**母版不是每种材料一块。** PT01/PT02、WF01/WF02 应共享参数化母版，仅字段值不同。允许完全不使用块：简单说明使用原生文字内容引线即可。

## 3. 基础母版规范

| 编号 | 母版 | 内容字段（示例） | 可选 / 变体 |
| --- | --- | --- | --- |
| A | 纯文字引线 | `noteText` | 多行说明、无边框 |
| B | 编号＋名称 | `categoryCode`, `typeNumber`, `displayName` | 左编号框 / 无框 |
| C | 材料编号＋说明 | `materialCode`, `typeNumber`, `materialName`, `specification?`, `method?` | 紧凑版 / 展开版 |
| D | 顶棚组合框 | `heightTag`, `elevation`, `materialCode`, `typeNumber`, `description?` | 四格 / 双行 / 仅标高 |
| E | 详图索引 | `detailId`, `sheetId` | 优先遵循项目索引标准，禁止混同材料编号 |
| F | 设备点位 | `symbolRef?`, `deviceCode?`, `height?`, `noteText?` | 原有设备符号＋引线，不强制新造块 |

外观应提供**左向、右向、上向、下向**连接点/对称排布规则；不针对四个方向分别维护四套业务字段。编号框、说明文字、引线根部在不同方向不能出现镜像倒字。

## 4. 初始编码字典（项目可覆写）

| 示例缩写 | 候选含义 | 示例 |
| --- | --- | --- |
| FF | 家具 / Furniture & Fixtures 类 | FF01 扶手椅 |
| CT | 瓷砖类 | CT01 |
| ST | 石材类 | ST01 |
| WF | 木地板类 | WF01 |
| PT | 涂料 / 乳胶漆类 | PT01 |
| WD | 木饰面类 | WD01 |
| MT | 金属饰面 / 收口类 | MT05 |
| CH | 顶棚标高字段标签（**不是材料编号**） | CH 2.600 |

以上是**默认候选词典，不是国标对照表**；各公司可能另有缩写。编号由“类型字典”分配，同一材料或家具类型在多处出现时允许共享同一编号；不应将每个锚点机械地生成一个新料号。类型定义与布置实例分开，允许“自动编号 / 人工编号 / 锁定编号”；重号冲突按项目字典检测。

## 5. 图面视觉规则

### 5.1 必须遵守的布局约束

1. **同一边的标签按一条标注基准线对齐**；左右侧以标签边缘对齐，上下侧以统一水平基线/边缘对齐。
2. 标签外包框（包括展开说明）之间**不可重叠**；间距根据实际文字外包框计算，而不是简单比较锚点距离。
3. 同侧间距采用**可配置的固定节距或统一最小净距**。排版时要考虑多行标签高度；无法等距时采用统一网格节距或可解释的分组间距。
4. 可选布置方向是左、右、上、下，允许同一图纸**多边共同分担标注**，不能固定为左侧一列。
5. 用户明确锁定的标签位置优先于自动优化；锁定导致冲突时报告冲突，不悄悄移动人工标注。
6. 引线不能穿过其他标签框，且应在指定标注安全区、图纸边界和需避让图形范围内寻路。

### 5.2 视觉优化目标（建议优先级）

在上述约束满足后，优先：**减少引线相交与重叠 → 同组尾线对齐 → 统一折角/角度族 → 减少拐点 → 减少总线长 → 左右上下视觉均衡**。切忌仅因最短路径而形成参差不齐的“蜘蛛网”。同一侧默认按目标锚点在该侧的投影顺序排列，降低交叉概率，但不等于保证全部无交叉。

角度先作为可调实验预设，而非一次冻结：`水平尾线＋自由斜段`、`水平尾线＋固定角度斜段`、`正交折线`。初始可比较 30°/45°/60° 等固定角度的可读性，**均是待实机测试的候选参数**。必要时允许局部突破角度统一以满足不穿框、不交叉等更高优先级约束。

### 5.3 建议参数（待样张测定，不是强制标准值）

- 文字高度、字宽系数、框内边距、行距、线宽、圆点/箭头尺寸均以**纸面视觉尺寸**定义，按模型空间与视口比例换算；注释比例与当前图纸比例必须明确。
- 同侧净距参数以纸面毫米计，建议先用 2 / 3 / 4 mm 三档制作 A3 样张对比后定默认值；多行文字优先满足实际外包框。
- 字体和图层遵循项目既有 STB、线宽与表达角色设置；不得以调整屏幕颜色替代打印线宽控制。
- 圆点 / 箭头 / 无端头可选；文字尾线左右端连接方式统一。

## 6. 手工交互与可编辑性

- 点选或框选多个锚点，按模板创建标注；也支持先创建标签后指定关联锚点。
- 支持“全自动四边分配”“限制在选中边”“指定若干允许区域”三种布局模式。
- 排版后可拖拽标签、修改引线折点、调整绑定点，并选择 `Auto` / `PositionLocked` / `Manual`。
- 提供“只整理已存在标注”操作；不强制重新生成材料、名称或文字内容。
- 文本和材料编号可独立修改；普通 DWG 打开时仍应可见、可打印，必要时可降级为原生文字/引线。

## 7. 样板制作与评审计划

1. 首批验证 **D 顶棚组合框** 和 **C 材料编号框**，另保留 A 纯文字引线的极简样例。
2. 为每种母版提供四向引线连接点、1 行/3 行说明、短/长中文、英文编号、同材重复位置样例。
3. 建立 A3 模型空间 / 布局 / PDF 三联样张；同时试黑白与彩色 STB。记录字体替代、线宽、字框压线、方向翻转及输出差异。
4. 用密集点位（例如 12、24、40 个）对比四边排布。测试不同密度下的交叉数、重叠数、对齐偏差、节距偏差、折角一致性和人工调整次数。
5. 若所有边都不足以排开，必须显示溢出/冲突提示，不能用重叠标注伪装成功。
6. **首版交付为规范与模板数据设计**；实际 DWG/DXF 图块、宿主与 PDF 样张由后续 AutoCAD 2027 实测 Gate 生成，不把未制成的图块写成“已完成”。

## 8. 待确认事项

- 编码字典与既有 CAD 图块、材料表的真实对应关系（尤其 `CH`、`ET` 的当前使用语义）。
- 顶棚标高基准、单位与数字格式（如 `2.600` 与 `2600`）。
- 材料编号框尺寸、文字高度、引线终点形状、默认线型与颜色。
- 左右/上下布局区域是否由用户框选、自动推导，或两者都提供。
- 上下边的标签纵向/横向排列方式、长文字换行与跨图纸空间限制。
